Hearth & Ledger — a fully offline household budget site for the fictional Alvarez household, seeded with a real November 2026 month: $4,892 income, $2,826.40 spending across 9 categories, and 3 savings goals. Five pages (Dashboard, Transactions, Categories, Goals, Reports) with add/edit/delete income and expenses, per-category budget limits with progress bars and over-budget warnings, savings-goal contributions, month stepping, transaction filter and search, canvas charts drawn in code, and localStorage persistence. Responsive, with a bottom nav on phones.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — no build step, no network requests, everything lives in `app/`.
